# УДАВ

Приложение батлов с тряской телефона. В каталоге [`udav/`](udav/) находятся обе версии:

- [`udav/src/`](udav/src/) — React + Vite, браузерная версия.
- [`udav/native/`](udav/native/) — React Native + Expo, Android-приложение.

Установка, запуск, сборка APK и ограничения прототипа описаны в [README проекта](udav/README.md).
