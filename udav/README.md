# УДАВ

Мобильная игра: два игрока трясут телефоны вверх-вниз и соревнуются, кто первым заполнит шкалу. Победа приносит 25 очков, поражение отнимает 15.

В репозитории две реализации интерфейса:

- Корень проекта — React + Vite, браузерное превью с рамками iPhone и Pixel.
- `native/` — настоящее приложение React Native + Expo SDK 58, без WebView.

Обе версии используют общие PNG, шрифты и каталог из 37 достижений. Есть рейтинг, профили, история батлов и витрина на три достижения. Описания достижений открываются по нажатию.

## Запуск браузерной версии

```sh
npm ci
npm run dev -- --host 127.0.0.1 --port 5173
```

Открыть http://127.0.0.1:5173/. Сборка: `npm run build`.

## Запуск React Native

```sh
cd native
npm ci
npm start
```

Открыть приложение на телефоне через совместимую версию Expo Go или установить APK. Android-приложение использует `expo-sensors` DeviceMotion: учитывает смену направления вертикального ускорения и отсекает быстрое вращение. Когда телефон перестают трясти, прогресс убывает. Ручной кнопки тряски нет.

## Сборка Android APK

В каталоге `native/`, с доступом к Expo-проекту команды `danila22811s-team`:

```sh
npx eas-cli@latest login
npx eas-cli@latest build --platform android --profile preview
```

Профиль `preview` создаёт APK для прямой установки. Профиль `production` создаёт Android App Bundle. Настройки находятся в `native/eas.json` и `native/app.json`. Ключи подписи хранятся в EAS, в Git их нет.

## Проверки

Из корня проекта:

```sh
npm run check:runtime
npm run build
node --test tests/battle-motion.test.mjs tests/visual-contract.test.mjs
```

В `native/`:

```sh
npx tsc --noEmit
npm run lint
npx expo export --platform android
```

Проверки сравнивают используемые PNG, файлы шрифтов, каталог достижений и правила подсчёта движения. Полное пиксельное совпадение требует сверки на настоящем устройстве; успешная сборка его не подтверждает. Автоматические браузерные тесты по решению автора не запускаются.

## Ограничения прототипа

Соперник и рейтинг моделируются локально. Настоящие сетевые батлы, сервер, авторизация и поиск людей поблизости пока не реализованы. Данные сбрасываются при перезапуске. Условия достижений — описания будущей механики, автоматической выдачи пока нет. Датчики нужно проверить на физическом телефоне.

Визуальные правила: `AGENTS.md`, `STICKER_GUIDE.md`, `design/native-parity.md`. Исходный главный макет сохранён в `public/assets/udav/reference.png`. Автономные локальные экспорты ревью, зависимости и результаты сборки в Git не включаются.
